# How to change the profile README

The profile is built like a film. There are two kinds of content:

| What | Where it lives | How to change it |
| :--- | :--- | :--- |
| **Plain text** — about me, experience table, skills, project cards, cast list, badges | [`/README.md`](../README.md) | Edit the Markdown directly. No tools needed. |
| **Animated graphics** — hero, tagline, scene slates, finale, end credits | `/assets/*.svg`, generated by [`gen.py`](gen.py) | Edit `gen.py`, run it, commit the new SVGs. |
| **Images** — key art, project posters | `/assets/*.jpg` | Replace the file (keep the same name) or add a new one. |
| **Contribution snake** | [`.github/workflows/snake.yml`](../.github/workflows/snake.yml) | Builds itself daily; colours are set in that file. |

> **Don't edit the `.svg` files by hand.** They're generated, and the next run of `gen.py` overwrites them. Each one also has the whole font packed inside it, so they're hard to read.

---

## 1. One-time setup

You'll need Python 3.9 or newer.

```bash
git clone https://github.com/Ankittian/Ankittian.git
cd Ankittian
pip install fonttools brotli
```

## 2. The edit → build → push loop

```bash
# 1. edit tools/gen.py (and/or README.md)
python tools/gen.py          # regenerates every SVG in assets/
# 2. preview: open any assets/*.svg in Chrome/Edge, or open README.md in VS Code preview
git add -A
git commit -m "Update profile"
git push
```

GitHub caches images for a few minutes, so if the profile still shows the old version, refresh after a short wait.

## 3. Recipes — things you'll most likely want to change

All line references are to `tools/gen.py`. Search (Ctrl+F) for the quoted text.

### Scene slates (the clapperboard dividers)

Find `SCENES = [`. Each line is one slate:

```python
(2, "CHARACTER STUDY", "THE PROTAGONIST", "Every story needs someone to root for."),
#│        │                    │                        └ logline (right side, small)
#│        │                    └ title (big, write it in CAPITALS)
#│        └ kicker (red line above the title)
#└ scene number → makes assets/slate-02.svg
```

- **Rename a scene:** change the text and run the script.
- **Add a scene:** add a line, e.g. `(9, "POST-CREDITS", "THE SEQUEL", "..."),`, set `TOTAL = 9`, run the script, then add it to `README.md`:
  ```html
  <img src="assets/slate-09.svg" width="100%" alt="Scene 09 — The Sequel"/>
  ```
- `TOTAL` controls the progress bar under each slate, so keep it equal to the last scene number.
- Keep titles to about 22 characters and loglines to about 50, or they'll run into each other.

### Tagline ("CODE IN THE DARK. / SHIP AT LIGHT SPEED.")

In `def tagline()`, edit the text inside the three `<text …>` tags:

- `CODE IN THE DARK.` is line 1 (solid white).
- `SHIP AT LIGHT SPEED.` is line 2 (outlined).
- `3D GAUSSIAN SPLATTING · AGENTIC RAG · …` is the small subtitle.

At font size 40, keep each line to about 22 characters.

### Hero banner (the opening shot)

- **The picture:** replace `tools/source/banner.webp` with any 3:1 image (the current one is 2172×724) and run the script.
- **Letterbox HUD text:** in `def hero()`, edit `SCENE 01 · THE OPENING`, `35MM · 2.39:1 · 24 FPS` and `IIT BHILAI '27 // AI RESEARCHER & DEVELOPER`. Write `&` as `&amp;`.

### Finale ("THE END … or is it?")

In `def finale()`, edit `THE END`, `…or is it?`, `COMING SOON`, `"YOUR PROJECT"` and `STARRING US BOTH.`

`wordmark("YOUR PROJECT", …)` draws text in your logo style, with every **A** turned into **Λ**.

### End credits

Edit the `CREDITS = [` list. It's pairs of `("ROLE", "NAME")`, and you can have as many as you like, because the roll length adjusts itself. The joke line at the bottom is in `def credits()`: search for `NO MODELS WERE OVERFIT`.

### Colours

The palette is the one line near the top of the file:

```python
RED, HOT, DEEP, BLOOD, INK, WHITE, ACC = (
    "#8e0a12", "#b3111c", "#4a0408", "#220103", "#0a0506", "#f6f3f0", "#ff3445")
```

| Name | Used for |
| :--- | :--- |
| `RED`, `HOT`, `BLOOD` | the crimson background gradient |
| `INK` | letterbox bars and dark panels |
| `WHITE` | all text |
| `ACC` | the bright red accents (REC dot, kickers, progress bar) |

If you change these, update the hex codes in `README.md` too (badges use `8e0a12` and `0a0506`; the stats cards use `220103` and `ff3445`) and in `snake.yml`.

### Speed of animations

Each graphic has its own CSS block inside its function. The durations are the `…s` values:

- `slam 9s`: how often the tagline replays
- `clap 6s`: how often the clapper snaps
- `roll 30s`: credits scroll speed (lower is faster)
- `end 11s`: the finale loop

## 4. Plain-text changes in README.md

| To change… | Look for… |
| :--- | :--- |
| About-me paragraph and `yaml` card | under `slate-02.svg` |
| Experience | the `REEL \| PRODUCTION` table |
| Skill icons | `skillicons.dev/icons?i=…`; IDs are listed at [skillicons.dev](https://skillicons.dev) |
| Full skills list | the `FULL CREW LIST` dropdown |
| Projects | the `<table>` under `slate-05.svg`, one `<td>` per project |
| Leadership | the `ROLE \| PLAYED AS` table |
| Links / email | the badges at the top and bottom (search for `img.shields.io`) |

### Adding a project card

1. Put a 16:9 image in `assets/`, e.g. `assets/poster-my-project.jpg`, about 900px wide.
2. Copy one `<td width="50%" valign="top"> … </td>` block and change the image, link, title, text and badges.
3. For a third project, start a new row: `</tr><tr>` before the new `<td>`.

### Badge recipe

```
https://img.shields.io/badge/<LABEL>-<TEXT>-8e0a12?style=for-the-badge&logo=<simpleicons-name>&logoColor=white&labelColor=0a0506
```

Use `_` for spaces and `--` for a dash. Logo names come from [simpleicons.org](https://simpleicons.org).

## 5. Troubleshooting

| Problem | Fix |
| :--- | :--- |
| `ModuleNotFoundError: fontTools` | `pip install fonttools brotli` |
| A character shows up in the wrong font | Only ASCII plus `· — … ’ ●` are packed into the SVGs. Add more code points in `_subset_font()` (the `unicodes=` list). |
| Text in an SVG overlaps | Shorten it. Michroma is a wide font, roughly 0.85 × font-size per character. |
| Snake image missing | Actions → *generate-snake-game* → **Run workflow**. It publishes to the `output` branch. |
| Stats card shows an error | Those are third-party services (`github-stats-extended`, `streak-stats`) that sometimes go down. Wait it out, or swap the URL. |
